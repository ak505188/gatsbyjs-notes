# Clair Obscur: Expedition 33 Any% Restricted
This is the updated route that uses Renoir 2&3 skips and no longer goes to Hidden Gestral Arena.
You can find the previous route [here.](/Expedition-33/Any-Restricted-Solo-Lune).

### Notation
For menus, I will sometimes have something in parenthesis. If it's (S1-3), it refers to the slot the Picto should be placed in. If it's a Playstation controller button, it's a button you should press to optimize the menu.

For battles, there will sometimes be something like (1.1 QTE). This refers to the Quick Time Action you do when you use an Ability. A perfect is 1.2, a normal is 1.1, and a fail is 1.0. The number refers to the damage multiplier the skill gets from the QTE.

For loading saves, I will use notation like load S0 to load the top save, or S2 to load the 3rd save (2 down).
These will assume no mistakes, since mistakes will often lead to extra saves. The notes will still describe which save to load.

There's also a debug reload you can do by pressing Alt+V. I will refer to this as **Debug Load**. You generally have to mash it as you enter an area, exit a menu, or load screen is ending.
